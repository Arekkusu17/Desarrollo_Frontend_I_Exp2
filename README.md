# TechNova Store

Actividad formativa de la Semana 4 para Desarrollo Frontend I. El proyecto consiste en una pagina web responsiva de productos tecnologicos, construida con Bootstrap 5 mediante CDN.

## Descripcion

TechNova Store presenta un catalogo simple de productos tech. La pagina incluye una barra de navegacion responsiva, un carrusel promocional, secciones organizadas con el sistema de grillas de Bootstrap y tarjetas de productos.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5 por CDN
- Imagenes locales en JPG
- Versiones WebP para mobile

## Requisitos implementados

- Navbar responsiva con Bootstrap.
- Carousel de Bootstrap configurado con cambio automatico cada 3 segundos.
- Sistema Grid para adaptar el contenido a distintos tamanos de pantalla.
- Cards para presentar productos tecnologicos.
- Codigo separado en HTML y CSS externo.
- Imagenes descargadas localmente para evitar dependencia de internet en recursos visuales.
- Versiones WebP optimizadas para mobile.
- Textos alternativos en imagenes para mejorar accesibilidad.
